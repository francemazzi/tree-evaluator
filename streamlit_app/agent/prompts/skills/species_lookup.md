## Species List Query Tool

Interroga una lista di specie vegetali (tassonomia + tratti) per fornire contesto botanico:
- Famiglia/ordine/classe
- Forma di crescita
- Tipo di foglia
- Sinonimi

Usa questo tool quando l'utente chiede contesto botanico sulle specie.

## Species List Query Tool

Query a plant species list (taxonomy + traits) to provide botanical context:
- Family/order/class
- Growth form
- Leaf type
- Synonyms

Use this tool when the user asks for botanical context about species.
