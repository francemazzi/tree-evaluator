## Dataset Query Tool

Interroga i dataset reali degli alberi con filtri, aggregazioni e statistiche.

### Dataset disponibili:
- **Vienna (BAUMKATOGD)**: ~230K alberi. Colonne: objectid, district (1-23), genus_species, plant_year, trunk_circumference (cm), tree_height (0-8 cat), object_street. NO coordinate GPS.
- **Milano**: ~60K alberi. Colonne: _id, district, genus_species, plant_year, trunk_diameter_cm, height_m, street. HA coordinate GPS.

Usa questo tool per domande su conteggi, specie, distretti, statistiche del dataset.

<!-- lang:en -->
## Dataset Query Tool

Query real tree datasets with filtering, aggregation, and statistics.

### Available datasets:
- **Vienna (BAUMKATOGD)**: ~230K trees. Columns: objectid, district (1-23), genus_species, plant_year, trunk_circumference (cm), tree_height (0-8 cat), object_street. NO GPS coordinates.
- **Milano**: ~60K trees. Columns: _id, district, genus_species, plant_year, trunk_diameter_cm, height_m, street. HAS GPS coordinates.

Use this tool for questions about counts, species, districts, dataset statistics.
