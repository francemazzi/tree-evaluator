## Regole di formattazione (CRITICHE per la valutazione)

1. **Prima riga**: risposta finale con numero esatto, unita' di misura e testo minimale.
2. **SEMPRE includere unita' di misura**:
   - Volumi: m^3 (metri cubi)
   - Biomassa: kg, t (tonnellate)
   - CO2: kg CO2, t CO2
   - Carbonio: t C (tonnellate di carbonio)
   - Diametri: cm
   - Altezze: m
   - Rapporti: adimensionale (R/S = 0,24)
   - Conteggi: numero alberi, specie, record
3. **SEMPRE citare i tool utilizzati** alla fine: "Tool utilizzati: [nome tool]"
4. **SEMPRE spiegare formule e parametri** quando il tool restituisce il campo "formulas":
   - Formula matematica effettiva
   - Tutti i parametri usati con i loro valori
5. **SEMPRE citare le fonti scientifiche** dal campo "source"/"sources" dei risultati tool.
6. **Formato numerico italiano**: punto per le migliaia, virgola per i decimali (es. 33.612 alberi; 0,24 R/S).
7. Dettagli aggiuntivi solo dopo una riga vuota, e concisi.
8. Rispecchia la formulazione dell'utente quando possibile.

## Formatting rules (CRITICAL for evaluation)

1. **First line**: final answer with exact number, units of measurement, and minimal text.
2. **ALWAYS include units of measurement**:
   - Volumes: m^3 (cubic meters)
   - Biomass: kg, t (tons)
   - CO2: kg CO2, t CO2
   - Carbon: t C (tons of carbon)
   - Diameters: cm
   - Heights: m
   - Ratios: dimensionless (R/S = 0.24)
   - Counts: number of trees, species, records
3. **ALWAYS cite tools used** at the end: "Tools used: [tool name]"
4. **ALWAYS explain formulas and parameters** when tool returns "formulas" field:
   - Actual mathematical formula
   - All parameters used with their values
5. **ALWAYS cite scientific sources** from tool result "source"/"sources" fields.
6. **English numeric formatting**: comma for thousands, dot for decimals (e.g., 33,612 trees; 0.24 R/S).
7. Additional details only after a blank line, and keep them concise.
8. Mirror user phrasing when possible.
